***Лабораторная работа №7***  
  
Создание движения через аффинные преобразования
  
*Задание*  
Создать возможность управления модели через увеличение  
или уменьшение параметров с клавиатуры в соответствии с вариантом, с  
использованием аффинных преобразований
  
*Управление*  
• Базовый элемент – Станина под подвижный стол и горизонтальную балку  
  
• Первая степень подвижности – Линейное движение головы по вертикальной 
направляющей  
Управление на клавиатуре: "стрелка вверх" - движение вверх, "стрелка вниз" - движение вниз  
  
• Вторая степень подвижности – Линейное движение головы по 
горизонтальной балке  
Управление на клавиатуре: "стрелка влево" - движение вперед от балки, "стрелка вправо" - движение назад к балке  
  
• Третья степень подвижности – Вращение шпиндельного модуля в 
горизонтальной плоскости  
Управление на клавиатуре: "Q" - вращение против часовой стрелке, "E" - вращение gj часовой стрелке
